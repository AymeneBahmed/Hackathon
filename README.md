# Language Living

Language Living is a TanStack Start + React application for practicing languages through AI-powered, real-world conversation scenarios.

## Prerequisites

- Node.js 20+
- npm

## Getting Started

```bash
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.

## Scripts

- `npm run dev` — start local dev server
- `npm run build` — build for production
- `npm run preview` — preview production build locally
- `npm run lint` — run ESLint

## Tech Stack

- TanStack Start + TanStack Router
- React + TypeScript
- Vite
- Supabase
